# AI-Based Fake Job and Internship Detector

## Project Overview
The AI-Based Fake Job and Internship Detector is a machine learning project developed to identify potentially fraudulent job and internship postings. The system analyses job-related information and predicts whether a posting is likely to be genuine or fraudulent.

The project aims to help job seekers make more informed decisions and stay aware of suspicious recruitment opportunities.

## Features
- Analyse job titles, descriptions, company profiles and other job-related details.
- Predict whether a job posting is potentially fake or likely genuine.
- Display estimated fake-job probability.
- Provide a risk assessment based on the prediction.
- Interactive web interface for entering and analysing job details.

## Technologies Used
- **Programming Language:** Python
- **Machine Learning:** Scikit-learn
- **NLP:** TF-IDF Vectorization
- **Algorithm:** Logistic Regression
- **Backend:** Flask
- **Frontend:** HTML, CSS
- **Data Processing:** Pandas, NumPy

## Dataset
The project uses a fake job postings dataset containing job-related information and labels indicating whether a posting is fraudulent or genuine.

## Methodology
1. Data collection and preprocessing.
2. Handling missing values and cleaning textual data.
3. Combining relevant job-related features.
4. Converting text into numerical features using TF-IDF.
5. Training a Logistic Regression classification model.
6. Integrating the trained model with a Flask web application.
7. Displaying prediction results through the website.

## How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/AI-Fake-Job-Detector.git
```

2. Navigate to the project directory:

```bash
cd AI-Fake-Job-Detector
```

3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

4. Run the Flask application:

```bash
python app.py
```

5. Open the following address in your browser:

```text
http://127.0.0.1:5000/
```

## Note
The predictions generated by this system are based on a trained machine learning model and should be treated as estimates, not definitive proof of job fraud. Users should independently verify job opportunities before sharing personal information or making payments.
